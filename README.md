# Mobile Home Android

Android-targeted React Native + Expo implementation of the mobile homepage
redesign for Phone and Pad.

- Runtime: React Native + Expo SDK 56
- Target platform: Android; web export is used for fast bundle validation
- Figma source: `移动端首页改版` (`tJamKVuAm0fELLoddNqQ9A`)
- Token baseline: `Browser Color System v3.0` (`106:3910`)
- Variable collection: `浏览器色彩 / Browser Color v3.0`

Phone is the current implemented surface. Pad remains a separate composition
to be implemented from its mapped source board after Phone verification.

Read `docs/PRODUCT_RESTORATION_PREFLIGHT.md` before implementing another
screen or state.
