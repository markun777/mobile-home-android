## 交互流程

```
首页（默认）
  │
  ├── 点搜索输入框 ──→ 搜索输入态（根据tab决定走AI还是全网）
  │     ├── AI搜索tab激活 → AI搜索输入页（571:44293）
  │     │     └── 工具栏：深入搜索 / 思考
  │     └── 搜全网tab激活 → 全网搜索输入页（571:44493）
  │           ├── 工具栏：引擎选择器（百度 + 下拉）
  │           └── 点引擎选择器 → 底部Sheet（选择搜索引擎）
  │
  ├── 输入内容并搜索 → 搜索结果页（571:44029）
  │
  ├── 点快捷方式图标 → 对应webview/应用
  │
  ├── 点底部「推荐」→ 推荐页（571:45836）
  ├── 点底部「视频」→ 视频tab
  ├── 点底部「小说」→ 小说tab
  └── 点底部「菜单」→ 菜单面板
```
